About

Development of a Gravity-Adaptive Gait Control Algorithm for a Bipedal Robot Using Arduino Mega: A Parametric Simulation Approach for Earth, Lunar, and Martian Environments

Bachelor thesis by Nikesh Gahatraj (ID 2317390), Department of Smart Computing, Kyungdong University Global. Supervisor: Dr. Nyrod Villa.

Findings

  • The model stood stably in all three gravities.
  • The hand-chosen gait fell in all six runs; scaling the frequency with gravity delayed the fall by 13.3% (Moon) and 11.4% (Mars).
  • After separate tuning, both controllers stayed upright for 12 s in all conditions.
  • Tuning mattered far more than the frequency law, and there was no single best controller.

Limitations

  • Results come from simulation only; nothing was measured on the robot.
  • One run per condition.
  • Idealised motors and exact tilt readings.
  • All joints bend in one plane.

How the site is built

Front endPlain HTML, CSS and JavaScript with canvas drawing. No framework.
Data layerSQLite database results.db exported to JSON in .
Backendbackend/: build script and a local REST server on the same database.
SimulationPython and PyBullet in simulation/.

Run it yourself

The real physics simulation

cd simulation
pip install -r requirements.txt
python simulate.py --gravity Moon --controller Adaptive --gait tuned --gui

The website with its REST API on your computer

python backend/build_db.py
python backend/server.py      # then open http://localhost:8000

Online, the site only replays saved results. The physics engine does not run in the browser.

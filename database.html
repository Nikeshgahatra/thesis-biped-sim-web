Database

Every number on this site comes from one SQLite database, results.db. A Python script (backend/build_db.py) loads the simulation CSV files into it and exports JSON files into . This page reads those files, so you can filter, sort and download the data.

GitHub Pages hosts static files only, so there is no live server online. To run the real REST API on SQLite, use python backend/server.py on your computer (see About). The SQL shown below is the query equivalent to your filters.

Table definition


Tables
  • runs: one row per run (gait, controller, environment, gravity, frequency, fall time, distance, largest pitch and roll).
  • timeseries: body position, height, pitch and roll every 0.1 s of every run.
  • params: the controller parameters of the first and the tuned gaits.
  • standing and foot_width: the static stability tests.
